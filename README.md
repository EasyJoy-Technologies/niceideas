# Niceideas

Niceideas is a self-built social platform for sharing ideas — short thoughts and long-form posts with images and audio — integrated with NiceNote sharing and NiceMatrix ID accounts.

## Domains
- Production: https://niceideas.app
- Staging: https://t.niceideas.app
