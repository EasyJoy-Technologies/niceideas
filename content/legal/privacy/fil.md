## 2. Impormasyon na kinokolekta namin

**Account at profile.** Kapag nagsign in ka gamit ang NiceMatrix ID, natatanggap namin ang account identifier at username ng iyong NiceMatrix ID, at ang iyong pangalan at larawan sa profile kung itinakda mo ito. Ginagamit namin ito upang likhain ang iyong profile: handle, display name, at avatar, kasama ang bio na iyong isinulat. **Nilalamang iyong ipinapaskil.** Mga post (teksto, titulo, larawan, at audio), ang mga naunang bersyon nito, mga setting ng post (tulad ng kung pinahintulutan ang mga komento), kung saan nagmula ang bawat post (web, NiceNote, o ibang app), at kung kailan ito naipaskil o nabago. Ang mga larawan ay nire-encode ulit kapag na-upload, na tinatanggal ang mga embedded metadata tulad ng lokasyon (EXIF). Ang mga audio file ay iniimbak kung paano ito na-upload, kasama ang anumang impormasyon na embedded dito.

**Mga interaksyon.** Mga like, komento, follow, at ulat. Kung magkomento ka nang walang account, iniimbak namin ang iyong komento at ang opsyonal na palayaw na iyong ilalagay. Ang mga naka-save (mga post na sine-save mo) ay ikaw lang ang nakakakita; ang post ay nagpapakita lang kung ilang tao ang nag-save nito. Puwede mong alisin ang isang naka-save anumang oras, at mabubura ang lahat ng ito kasama ng iyong account. Pampubliko ang mga repost: nakikita ng mga follower mo ang mga post na nire-repost mo, at ipinapakita ng profile mo ang iyong mga repost, quote at mga komentong isinulat mo habang naka-sign in. Maaari mong i-undo ang repost anumang oras.

**Teknikal at pangseguridad na impormasyon.** Upang maiwasan ang abuso, lumilikha kami ng mga keyed one-way code ("hash") mula sa isang random na browser identifier at mula sa iyong IP address, at iniimbak ang mga code na ito sa lugar ng IP address mismo kasama ng mga like, komento, at ulat. Ang aming web server ay nagtatago ng access log na may IP address, oras, hiniling na page, at tipo ng browser. Sinasabi sa amin ng aming network provider ang bansa kung saan galing ang isang kahilingan; ginagamit lamang namin ito upang ipatupad ang mga panrehiyong alituntunin sa Seksyon 8 at hindi namin ito iniimbak kasama ang iyong profile o nilalaman. Upang mapigilan ang automated spam, nagsasagawa ang iyong browser ng isang maliit na computational check kapag ikaw ay nagkomento nang walang account; hindi kami gumagamit ng third-party na CAPTCHA.

**Mga sign-in session.** Kapag nagsign in ka sa web, iniimbak namin ang isang session record: isang one-way hash ng session code, ang account identifier mo, at kung kailan nalikha, huling ginamit, at mag-expire ang session.

**Impormasyon mula sa NiceMatrix ID.** Kapag humiling ka ng pagbura ng NiceMatrix ID, kinansel ang kahilingang iyon, o natapos ang pagbura, ipinaaalam ng NiceMatrix ID ang niceideas upang makilos kami nang angkop.

**Impormasyon mula sa mga app na iyong awtorisado.** Ipinapadala sa amin ng mga app na iyong awtorisado ang mga post at media na iyong ipinapaskil sa pamamagitan ng mga ito, kasama ang identifier ng app.

**Analytics ng paggamit (sa iyong pahintulot lamang).** Kung tatanggapin mo ang mga analytics cookie, gumagamit kami ng Google Analytics (Google) at Microsoft Clarity (Microsoft) upang maunawaan kung paano ginagamit ang mga web page at mapahusay ang mga ito. Kinokolekta ng mga tool na ito ang mga page na binibisita mo, mga click, pag-scroll at galaw ng mouse, ang iyong tinatayang lokasyon na hinango mula sa iyong IP address, impormasyon tungkol sa device at browser, at mga pseudonymous identifier na nakaimbak sa mga cookie. Gumagawa rin ang Microsoft Clarity ng mga session replay at heatmap; isinasaayos namin ito upang itago ang lahat ng teksto sa page, kasama ang anumang tina-type mo, kaya hindi nito nire-record ang nilalaman ng mga post, komento, o form. Pinapatay namin ang mga advertising feature ng Google, at hindi namin ginagamit ang mga tool na ito sa page ng Mga setting, sa mga moderation page, o para sa mga koneksyon mula sa mainland China. Kung tatanggihan mo ang mga analytics cookie o hindi ka pipili, hindi nilo-load ang mga tool na ito.

**Ang hindi namin kinokolekta.** Hindi kami gumagamit ng mga advertising o social-media tracking tool, hindi gumagawa ng mga advertising profile, o kumokolekta ng tumpak na lokasyon.
