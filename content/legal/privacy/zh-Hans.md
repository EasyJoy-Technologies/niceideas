## 2. 我们收集的信息

**账号和个人资料。** 你使用 NiceMatrix ID 登录时，我们会收到你的 NiceMatrix ID 账号标识和用户名，以及你已设置的名字和头像。我们用这些信息创建你的个人资料：用户名、显示名称和头像，以及你自己填写的简介。我们不会收到你的密码、电子邮箱或手机号码。

**你发布的内容。** 帖子（文字、标题、图片和音频）、其历史版本、帖子设置（例如是否允许评论）、每篇帖子的来源（网页、乐趣记事本或其他应用），以及发布或修改的时间。图片上传时会重新编码，从而去除位置（EXIF）等内嵌元数据。音频文件按上传原样保存，包括其中内嵌的任何信息。

**互动。** 点赞、评论、关注和举报。如你未登录发表评论，我们会保存你的评论和你填写的可选昵称。收藏（你保存的帖子）只有你自己能看到；帖子上只显示有多少人收藏。你可以随时取消收藏，注销账号时全部删除。转发是公开的：关注你的人会看到你转发的帖子，你的个人主页会列出你的转发、引用以及你登录时发表的评论。你可以随时撤销转发。

**技术和安全信息。** 为防止滥用，我们会根据一个随机浏览器标识和你的 IP 地址生成带密钥的单向代码（“哈希”），并将这些代码而非 IP 地址本身与点赞、评论和举报一起保存。我们的网页服务器会保留访问日志，其中包括 IP 地址、时间、所访问页面和浏览器类型。我们的网络服务商会告知我们请求来自哪个国家或地区；我们仅用它来执行第 8 条所述的地区规则，不会将其与你的个人资料或内容一起保存。为防止自动化垃圾信息，你在未登录状态下评论时，浏览器会完成一个小型计算校验；我们不使用外部验证码服务。

**登录会话。** 你在网页上登录时，我们会保存一条会话记录：会话代码的单向哈希、你的账号标识，以及会话的创建、最近使用和到期时间。

**来自 NiceMatrix ID 的信息。** 当你申请删除 NiceMatrix ID、取消该申请或删除完成时，NiceMatrix ID 会通知 niceideas，以便我们相应处理。

**来自你授权的应用的信息。** 你授权的应用会向我们发送你通过它们发布的帖子和媒体，以及该应用的标识。

**使用分析（仅在你同意的情况下）。** 如你同意使用分析类 Cookie，我们会使用 Google Analytics（Google）和 Microsoft Clarity（Microsoft）来了解人们如何使用网页并加以改进。这些工具会收集你访问的页面、点击、滚动和鼠标移动，根据你的 IP 地址推算出的大致位置、设备和浏览器信息，以及保存在 Cookie 中的假名化标识符。Microsoft Clarity 还会生成会话回放和热图；我们已将其配置为隐藏页面上的所有文字，包括你输入的任何内容，因此不会记录帖子、评论或表单的内容。我们会关闭 Google 的广告功能，并且不在“设置”页面、管理页面或来自中国大陆的连接上使用这些工具。如你拒绝使用分析类 Cookie 或未作选择，这些工具将不会加载。

**我们不收集的信息。** 我们不使用广告或社交媒体跟踪工具，不建立广告画像，也不收集精确位置。我们不会要求你提供敏感信息，但如你选择发布，你的帖子可能会透露这类信息。
