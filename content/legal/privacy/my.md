**သင်တင်သော အကြောင်းအရာ။** ပို့စ်များ (စာသား၊ ခေါင်းစီးများ၊ ပုံများနှင့် အသံ)၊ ၎င်းတို့၏ ယခင် ဗားရှင်းများ၊ ပို့စ် သတ်မှတ်ချက်များ (ဥပမာ၊ မှတ်ချက်များ ခွင့်ပြုထားခြင်းရှိ မရှိ)၊ ပို့စ်တစ်ခုစီ မည်သည့်နေရာမှလာကြောင်း (ဝက်ဘ်၊ NiceNote သို့မဟုတ် အခြားအက်ပ်) နှင့် ၎င်းကို ထုတ်ဝေခဲ့ သို့မဟုတ် ပြောင်းလဲခဲ့သည့် အချိန်။ ပုံများသည် upload လုပ်သောအခါ ထပ်မံ encode ပြုလုပ်ခံရသည်၊ ၎င်းသည် တည်နေရာ (EXIF) ကဲ့သို့ ထည့်သွင်းထားသော metadata များကို ဖယ်ရှားသည်။ အသံဖိုင်များသည် upload လုပ်ထားသည့်အတိုင်း သိမ်းဆည်းထားသည်၊ ၎င်းတို့တွင် ထည့်သွင်းထားသော မည်သည့်အချက်အလက်များမဆို အပါအဝင်။

**တုံ့ပြန်မှုများ။** ကြိုက်နှစ်သက်မှုများ၊ မှတ်ချက်များ၊ follower များနှင့် တိုင်ကြားမှုများ။ သင်အကောင့်မပါဘဲ မှတ်ချက်ပေးပါက၊ ကျွန်ုပ်တို့သည် သင့်မှတ်ချက်နှင့် သင်ထည့်သွင်းထားသော ရွေးချယ်ခွင့်ရှိသော အမည်ပျောက်ကို သိမ်းဆည်းသည်။ သိမ်းထားသည်များ (သင်သိမ်းထားသော ပို့စ်များ) ကို သင်တစ်ဦးတည်းသာ မြင်ရပြီး ပို့စ်တွင် သိမ်းထားသူ အရေအတွက်ကိုသာ ပြသည်။ သိမ်းထားမှုကို အချိန်မရွေး ဖယ်ရှားနိုင်ပြီး သင့်အကောင့်နှင့်အတူ အားလုံး ဖျက်ပစ်ပါမည်။ ပြန်တင်ခြင်းများသည် အများမြင်ဖြစ်သည်- သင့်နောက်လိုက်များသည် သင်ပြန်တင်သော ပို့စ်များကို မြင်ရပြီး သင့်ပရိုဖိုင်တွင် သင်၏ ပြန်တင်မှုများ၊ ကိုးကားချက်များနှင့် အကောင့်ဝင်ထားစဉ် ရေးသားခဲ့သော မှတ်ချက်များကို ပြသသည်။ ပြန်တင်ခြင်းကို အချိန်မရွေး ပယ်ဖျက်နိုင်သည်။

**နည်းပညာနှင့် လုံခြုံရေးအချက်အလက်။** အလွဲသုံးစားကို ကာကွယ်ရန်၊ ကျွန်ုပ်တို့သည် ကျပန်း browser identifier မှနှင့် သင့် IP လိပ်စာမှ key ပါသော one-way code များ ("hashes") ကို ဖန်တီးပြီး ဤ code များကို IP လိပ်စာကိုယ်တိုင်အစား ကြိုက်နှစ်သက်မှုများ၊ မှတ်ချက်များနှင့် တိုင်ကြားမှုများဖြင့် သိမ်းဆည်းသည်။ ကျွန်ုပ်တို့၏ ဝက်ဘ်ဆာဗာသည် IP လိပ်စာ၊ အချိန်၊ တောင်းဆိုထားသော စာမျက်နှာနှင့် browser အမျိုးအစားရှိသော access log များကို သိမ်းဆည်းသည်။ ကျွန်ုပ်တို့၏ network provider သည် တောင်းဆိုမှုတစ်ခုသည် မည်သည့်နိုင်ငံမှလာကြောင်း ကျွန်ုပ်တို့ကို ပြောသည်; ၎င်းကို ကျွန်ုပ်တို့သည် Section 8 ရှိ ဒေသဆိုင်ရာစည်းမျဉ်းများကို အကျိုးသက်ရောက်စေရန်သာ သုံးပြီး သင့်ပရိုဖိုင် သို့မဟုတ် အကြောင်းအရာနှင့်အတူ ၎င်းကို မသိမ်းဆည်းပါ။ အလိုအလျောက် spam ကို ကာကွယ်ရန်၊ သင်အကောင့်မပါဘဲ မှတ်ချက်ပေးသောအခါ သင့် browser သည် သေးငယ်သော calculation checks ကို ဖြေရှင်းသည်; ကျွန်ုပ်တို့သည် ပြင်ပ CAPTCHA ကို မသုံးပါ။

**ဝင်ရောက်မှု session များ။** ဝက်ဘ်ပေါ်တွင် ဝင်ရောက်သောအခါ၊ ကျွန်ုပ်တို့သည် session record တစ်ခုကို သိမ်းဆည်းသည်: session code ၏ one-way hash၊ သင့် account identifier နှင့် session သည် ဖန်တီးခဲ့သည့်၊ နောက်ဆုံးသုံးစွဲခဲ့သည့်နှင့် သက်တမ်းကုန်ဆုံးမည့်အချိန်။

**သင်ခွင့်ပြုသော အက်ပ်များမှ ရရှိသော အချက်အလက်။** သင်ခွင့်ပြုသော အက်ပ်များသည် ၎င်းတို့မှတစ်ဆင့် သင်တင်သော ပို့စ်များနှင့် မီဒီယာကို၊ အက်ပ် identifier နှင့်အတူ ကျွန်ုပ်တို့ထံ ပေးပို့သည်။

**အသုံးပြုမှု analytics (သင့်သဘောတူညီချက်ဖြင့်သာ)။** သင်က analytics cookie များကို လက်ခံပါက ဝဘ်စာမျက်နှာများကို မည်သို့အသုံးပြုကြောင်း နားလည်ပြီး ပိုမိုကောင်းမွန်အောင် ပြုလုပ်ရန် Google Analytics (Google) နှင့် Microsoft Clarity (Microsoft) ကို ကျွန်ုပ်တို့ သုံးသည်။ ဤ tool များသည် သင်ကြည့်ရှုသော စာမျက်နှာများ၊ click များ၊ scroll လုပ်ခြင်းနှင့် mouse လှုပ်ရှားမှုများ၊ သင့် IP လိပ်စာမှ ခန့်မှန်းရရှိသော အနီးစပ်ဆုံးတည်နေရာ၊ device နှင့် browser အချက်အလက်များနှင့် cookie များတွင် သိမ်းဆည်းထားသော pseudonymous identifier များကို စုဆောင်းသည်။ Microsoft Clarity သည် session replay များနှင့် heatmap များကိုလည်း ဖန်တီးသည်; သင်ရိုက်ထည့်သည့်အရာ အပါအဝင် စာမျက်နှာပေါ်ရှိ စာသားအားလုံးကို ဖုံးကွယ်ရန် ကျွန်ုပ်တို့ စီစဉ်ထားသဖြင့် ပို့စ်များ၊ မှတ်ချက်များ သို့မဟုတ် form များ၏ အကြောင်းအရာကို မှတ်တမ်းမတင်ပါ။ Google ၏ ကြော်ငြာ feature များကို ကျွန်ုပ်တို့ ပိတ်ထားပြီး ဆက်တင်များ စာမျက်နှာ၊ moderation စာမျက်နှာများ သို့မဟုတ် တရုတ်ပြည်မကြီးမှလာသော connection များအတွက် ဤ tool များကို မသုံးပါ။ သင်က analytics cookie များကို ငြင်းပယ်ပါက သို့မဟုတ် မရွေးချယ်ပါက ဤ tool များကို load မလုပ်ပါ။

**ကျွန်ုပ်တို့ မစုဆောင်းသောအရာ။** ကြော်ငြာ သို့မဟုတ် social-media tracking tool များကို ကျွန်ုပ်တို့ မသုံးပါ၊ ကြော်ငြာ profile များကို မဖန်တီးပါ သို့မဟုတ် တိကျသောတည်နေရာကို မစုဆောင်းပါ။ ကျွန်ုပ်တို့သည် ထိလွယ်ရှလွယ်သော အချက်အလက်များကို မတောင်းဆိုပါ၊ သို့သော် သင်တင်ရန် ရွေးချယ်ပါက သင့်ပို့စ်များသည် ၎င်းကို ဖော်ပြနိုင်သည်။

## 3. ကျွန်ုပ်တို့ အချက်အလက်များကို မည်သို့သုံးပြီး အဘယ်ကြောင့်

| ရည်ရွယ်ချက် | အချက်အလက် | ဥပဒေဆိုင်ရာ အခြေခံ (လိုအပ်ပါက၊ ဥပမာ GDPR) |
|---|---|---|

| လူများကို ကြိုက်နှစ်သက်ခွင့်နှင့် မှတ်ချက်ပေးခွင့်ပြုခြင်း၊ အကောင့်မပါဘဲ အပါအဝင် | တုံ့ပြန်မှုများ၊ အမည်ပျောက်၊ hashes | စာချုပ် (account holders); ပွင့်လင်းသောဆွေးနွေးမှုအတွက် တရားဝင်အကျိုးစီးပွား (လာလည်သူများ) |
| spam, လိမ်လည်မှုနှင့် အလွဲသုံးစားကို ကာကွယ်ခြင်း; ကျွန်ုပ်တို့၏ စည်းမျဉ်းများကို အကျိုးသက်ရောက်စေခြင်း; တိုင်ကြားမှုများကို ကိုင်တွယ်ခြင်း | hashes, logs, တိုင်ကြားမှုများ, moderation records | လုံခြုံသော ဝန်ဆောင်မှုအတွက် တရားဝင်အကျိုးစီးပွား; ဥပဒေဆိုင်ရာတာဝန်များ |
| ဒေသဆိုင်ရာ ဝင်ရောက်ခွင့်စည်းမျဉ်းများကို အကျိုးသက်ရောက်စေခြင်း | တောင်းဆိုမှု၏နိုင်ငံ | တရားဝင်အကျိုးစီးပွား; ဥပဒေဆိုင်ရာတာဝန်များ |
| ဝန်ဆောင်မှုကို လုံခြုံပြီး အလုပ်လုပ်နေအောင် ထားရှိခြင်း; အမှားများကို ပြင်ဆင်ခြင်း | logs, session records | တရားဝင်အကျိုးစီးပွား |

| သင့်တောင်းဆိုမှုများကို ပြန်လည်ဖြေကြားခြင်းနှင့် တရားဝင် claim များကို ကိုင်တွယ်ခြင်း | သင့်တောင်းဆိုမှုရှိ အချက်အလက် | ဥပဒေဆိုင်ရာတာဝန်များ; တရားဝင်အကျိုးစီးပွား |

အကြောင်းအရာနှင့် အကောင့်များအကြောင်း ဆုံးဖြတ်ချက်များကို လူများမှ ပြုလုပ်သည်။ Automatic rate limits များသည် လုပ်ဆောင်ချက်များကို နှေးသွားစေ သို့မဟုတ် ခေတ္တပိတ်ဆို့ရုံသာ ဖြစ်သည်; သင့်အပေါ် ဥပဒေဆိုင်ရာ သို့မဟုတ် ထို့အလားတူသိသာသော သက်ရောက်မှုရှိသော automated decision များကို ကျွန်ုပ်တို့ မဆုံးဖြတ်ပါ။

ကနေဒါ၏ ကိုယ်ပိုင်အချက်အလက်ဥပဒေအောက်တွင်၊ ဤမူဝါဒကို ဖတ်ပြီးနောက် ဝန်ဆောင်မှုကို သုံးစွဲခြင်းဖြင့် သင်ပေးသော သင့်သဘောတူညီချက်အပေါ်၊ သို့မဟုတ် သင့်လျော်သောနေရာတွင် implied consent အပေါ် ကျွန်ုပ်တို့ မှီတည်သည်။ သင်သည် ဥပဒေဆိုင်ရာ သို့မဟုတ် စာချုပ်ကန့်သတ်ချက်များကို လိုက်နာရန်ဖြစ်၍၊ သင့်သဘောတူညီချက်ကို အချိန်မရွေး ရုတ်သိမ်းနိုင်သည်; ၎င်းသည် ဝန်ဆောင်မှု၏ အချို့ သို့မဟုတ် အားလုံးကို သင် နောက်ထပ် မသုံးစွဲနိုင်ကြောင်း ဆိုလိုနိုင်သည်။

## 4. အများမြင် အချက်အလက်

သင့်ပရိုဖိုင် (အသုံးပြုသူအမည်၊ ပြသအမည်၊ avatar၊ bio၊ ပါဝင်သည့်ရက်စွဲ၊ ပို့စ်အရေအတွက်၊ follower၊ follow လုပ်ထားသော အကောင့်များနှင့် ရရှိထားသော ကြိုက်နှစ်သက်မှုများ)၊ သင့်ပို့စ်များနှင့် မှတ်ချက်များသည် အများမြင်ရသည်။ အကောင့်မရှိသော သူများအပါအဝင် မည်သူမဆို ၎င်းတို့ကို ကြည့်ရှုနိုင်သည်; ရှာဖွေမှု engine များသည် ၎င်းတို့ကို index ပြုလုပ်နိုင်သည်; နှင့် အခြား platform များသည် ၎င်းတို့၏ link preview များကို ပြသနိုင်သည်။ လာလည်သူ၏ မှတ်ချက်ပေါ်ရှိ အမည်ပျောက်သည် အများမြင်ရသည်။ IP လိပ်စာများနှင့် browser identifier များမှ ရရှိသော code များကို တစ်ခါမျှ မပြသပါ။

သင်သာ မြင်ရအောင် ပြုလုပ်ထားသော ပို့စ်များသည် အများမြင်ရခြင်း မဟုတ်ပါ- ၎င်းတို့ကို သင်သာ မြင်နိုင်ပြီး ထိုသို့ ရှိနေသရွေ့ ၎င်းတို့၏ ပုံများနှင့် အသံများကို အများ ဝင်ကြည့်၍ မရပါ။

## 5. Cookie များ

ဝန်ဆောင်မှု အလုပ်လုပ်ရန် လိုအပ်သော cookie များကိုလည်းကောင်း၊ သင်လက်ခံမှသာ analytics cookie များကိုလည်းကောင်း ကျွန်ုပ်တို့ သုံးသည်။ ကြော်ငြာ cookie များကို ကျွန်ုပ်တို့ မသုံးပါ။

**လိုအပ်သော cookie များ**

| Cookie | ရည်ရွယ်ချက် | ကြာချိန် |
|---|---|---|

ကိုယ်ပိုင်အချက်အလက်များကို ကျွန်ုပ်တို့ မရောင်းပါ သို့မဟုတ် မငှားရမ်းပါ၊ ၎င်းကို cross-context behavioural advertising အတွက် မျှဝေမည်မဟုတ်ပါ။ ကျွန်ုပ်တို့သည် ၎င်းကို အောက်ပါများနှင့်သာ မျှဝေသည်:

- **NiceMatrix ID**၊ ကျွန်ုပ်တို့ လည်ပတ်သော sign-in ဝန်ဆောင်မှု၊ သင့်ကို sign in ပြုလုပ်ရန်နှင့် account deletion ကို ဆောင်ရွက်ရန်။

## 7. နိုင်ငံတကာ လွှဲပြောင်းမှုများ

NiceMatrix သည် ကနေဒါတွင် အခြေစိုက်သည်။ ကျွန်ုပ်တို့၏ ဆာဗာများနှင့် media storage သည် ဥရောပ (ဂျာမနီနှင့် ဥရောပအနောက်ပိုင်း) တွင်ရှိပြီး၊ ကျွန်ုပ်တို့၏ network provider သည် သင့်နှင့် အနီးဆုံးနိုင်ငံတွင် တောင်းဆိုမှုများကို ကိုင်တွယ်သည်။ ထို့ကြောင့် သင့်အချက်အလက်ကို ဂျာမနီ၊ အခြားဥရောပနိုင်ငံများ၊ ကနေဒါနှင့် ကျွန်ုပ်တို့၏ provider များ အလုပ်လုပ်သည့် အခြားနိုင်ငံများတွင် ကိုင်တွယ်နိုင်ပြီး၊ ၎င်းတို့၏ ဥပဒေများသည် သင့်နိုင်ငံ၏ ဥပဒေများနှင့် ကွဲပြားနိုင်သည်။

သင်က analytics cookie များကို လက်ခံပါက Google နှင့် Microsoft သည် analytics ဒေတာကို အမေရိကန်နှင့် ၎င်းတို့ လုပ်ကိုင်သော အခြားနိုင်ငံများတွင် ကိုင်တွယ်သည်။

ဥရောပ စီးပွားရေးဒေသ၊ UK နှင့် Switzerland မှ ကနေဒါသို့ လွှဲပြောင်းမှုများသည် ကနေဒါအတွက် adequacy decision များအပေါ် မှီတည်သည်။ အမေရိကန်ရှိ Google နှင့် Microsoft သို့ လွှဲပြောင်းမှုများသည် ကုမ္ပဏီနှစ်ခုစလုံး certified ဖြစ်သော EU-U.S. Data Privacy Framework နှင့် ၎င်း၏ UK နှင့် Swiss extension များအပေါ် သို့မဟုတ် Standard Contractual Clauses အပေါ် မှီတည်သည်။ အခြား လွှဲပြောင်းမှုများသည် ကျွန်ုပ်တို့၏ provider များ၏ data processing terms တွင် ပါဝင်သော Standard Contractual Clauses အပေါ် သို့မဟုတ် ဥပဒေအရ အသိအမှတ်ပြုထားသော အခြားကာကွယ်မှုများအပေါ် မှီတည်သည်။

1. ဖျက်သိမ်းရန် တောင်းဆိုသောအခါ၊ သင့် niceideas ပရိုဖိုင်နှင့် ပို့စ်များသည် ချက်ချင်း offline ဖြစ်သွားသည်။
2. NiceMatrix ID ၏ ပြန်ပြင်ကာလ (ယခု ၁၅ ရက်) အတွင်း ပယ်ဖျက်ပါက၊ အရာအားလုံးသည် တူညီသောလင့်များတွင် ပြန်ရောက်လာသည်။
3. ပြန်ပြင်ကာလ ကုန်ဆုံးသောအခါ၊ ၁၄ ရက်အထိ backup cycle မှလွဲ၍ အခြားထပ်ဆောင်း retention period မရှိဘဲ၊ သင့်ပရိုဖိုင်၊ ပို့စ်များ၊ ယခင် ဗားရှင်းများ၊ media, မှတ်ချက်များ၊ ကြိုက်နှစ်သက်မှုများနှင့် follower များကို ကျွန်ုပ်တို့ အပြီးအပိုင် ဖျက်သိမ်းသည်။

သင်သည် တစ်သီးတစ်ခြား ပို့စ်များကိုလည်း အချိန်မရွေး ဖျက်နိုင်ပြီး၊ သို့မဟုတ် အခြားအရာကို ဖျက်သိမ်းရန် ကျွန်ုပ်တို့ထံ ရေးသားနိုင်သည်။

- သင့်အချက်အလက်ကို ဖျက်သိမ်းရန်;
- legitimate interest အပေါ် မှီတည်သော processing အပါအဝင် အချို့ processing များကို ကန့်ကွက် သို့မဟုတ် ကန့်သတ်ရန်;
- သင့်သဘောတူညီချက်ကို ရုတ်သိမ်းရန်;
- data protection authority တစ်ခုထံ တိုင်ကြားရန်၊ ဥပမာ Office of the Privacy Commissioner of Canada, Office of the Information and Privacy Commissioner of Alberta, European Union ရှိ သင့် local authority, သို့မဟုတ် UK Information Commissioner's Office။

## 13. လုံခြုံရေး

ကျွန်ုပ်တို့သည် အချက်အလက်များကို transit (HTTPS) တွင် encryption ဖြင့်၊ raw session code များအစား one-way hashes ဖြင့်၊ IP လိပ်စာများနှင့် browser identifier များ၊ ကျွန်ုပ်တို့ ဝန်ဆောင်မှုများအကြား signed messages, authorised ဝန်ထမ်းများသို့သာ ကန့်သတ်ထားသော access, Section 2 ရှိ သင်လက်ခံပြီးမှသာ load လုပ်သော optional analytics tool များမှလွဲ၍ ပြင်ပ scripts များကို ခွင့်မပြုသော strict content security policy, နှင့် ကန့်သတ်ထားသော အချိန်အတွင်း ထားရှိသော daily backup များဖြင့် ကာကွယ်သည်။ မည်သည့်စနစ်မျှ လုံးဝလုံခြုံသည်မဟုတ်ပါ။ security breach တစ်ခုသည် သိသာထင်ရှားသော ဆုံးရှုံးမှုအတွက် real risk တစ်ခုကို ဖန်တီးပါက၊ ဥပဒေက တောင်းဆိုသည့်အတိုင်း သင့်ကိုနှင့် authorities များကို ကျွန်ုပ်တို့ အသိပေးပါမည်။

ပြီးခဲ့သော ၁၂ လအတွင်း၊ ကျွန်ုပ်တို့သည် identifier များ (account identifier, handle, hashed IP addresses and browser identifiers), internet activity (logs, interactions နှင့် သင်က analytics cookie များကို လက်ခံပါက အသုံးပြုမှု analytics) နှင့် သင်တင်သော အကြောင်းအရာကို၊ Section 2 နှင့် 3 တွင် ဖော်ပြထားသော source များနှင့် ရည်ရွယ်ချက်များအတွက် စုဆောင်းခဲ့သည်။ ကျွန်ုပ်တို့သည် ဤအချက်အလက်ကို Section 6 တွင် ဖော်ပြထားသော service provider များသို့ business purpose များအတွက်သာ ဖော်ပြခဲ့ပြီး သင်က analytics cookie များကို လက်ခံပါက အသုံးပြုမှု analytics အတွက် Google နှင့် Microsoft လည်း ပါဝင်သည်။ ကိုယ်ပိုင်အချက်အလက်များကို cross-context behavioural advertising အတွက် ကျွန်ုပ်တို့ မရောင်းပါ သို့မဟုတ် မမျှဝေပါ၊ သင့်အကြောင်း ဝိသေသလက္ခဏာများကို ခန့်မှန်းရန် sensitive personal information ကို ကျွန်ုပ်တို့ မသုံးပါ။ Retention ကို Section 9 တွင် ဖော်ပြထားသည်။
