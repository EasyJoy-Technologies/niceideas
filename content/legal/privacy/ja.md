## 2. 当社が収集する情報

**アカウントとプロフィール。** NiceMatrix ID でサインインすると、当社はあなたの NiceMatrix ID アカウント識別子とユーザー名、設定している場合は名前とプロフィール画像を受け取ります。これらを使用してあなたのプロフィール（ハンドル、表示名、アバター）と、あなたが記入した自己紹介を作成します。当社はあなたのパスワード、メールアドレス、電話番号を受け取りません。

**あなたが公開するコンテンツ。** 投稿（テキスト、タイトル、画像、音声）、それ以前のバージョン、投稿設定（例えばコメントを許可するかどうか）、各投稿の出所（ウェブ、NiceNote、または他のアプリ）、公開または変更された日時。画像はアップロード時に再エンコードされ、位置情報（EXIF）などの埋め込みメタデータが削除されます。音声ファイルはアップロードされたまま保存され、その中に埋め込まれた情報も含まれます。

**インタラクション。** いいね、コメント、フォロー、報告。アカウントなしでコメントする場合、当社はあなたのコメントと入力した任意のニックネームを保存します。保存した投稿（ブックマーク）はあなただけが見られます。投稿に表示されるのは保存した人数だけです。保存はいつでも解除でき、アカウントの削除とともにすべて削除されます。

**技術およびセキュリティ情報。** 不正利用を防止するため、当社はランダムなブラウザ識別子とあなたの IP アドレスから鍵付きの一方向コード（「ハッシュ」）を作成し、IP アドレス自体の代わりにこれらのコードをいいね、コメント、報告とともに保存します。当社のウェブサーバーは、IP アドレス、時刻、要求されたページ、ブラウザの種類を含むアクセスログを保持します。当社のネットワークプロバイダーはリクエストがどの国から来たかを当社に伝えますが、当社はこれを第8条に記載されている地域ルールの適用のみに使用し、あなたのプロフィールやコンテンツとともに保存することはありません。自動化されたスパムを抑制するため、アカウントなしでコメントする際にブラウザが小さな計算チェックを解決しますが、当社は外部の CAPTCHA を使用しません。

**サインインセッション。** ウェブでサインインすると、当社はセッション記録を保存します：セッションコードの一方向ハッシュ、あなたのアカウント識別子、およびセッションが作成、最後に使用、期限切れになる時刻です。

**NiceMatrix ID からの情報。** あなたが NiceMatrix ID の削除を依頼したとき、その依頼を取り消したとき、または削除が完了したとき、NiceMatrix ID は niceideas に通知し、当社が対応できるようにします。

**あなたが承認したアプリからの情報。** あなたが承認したアプリは、それらを通じて公開した投稿とメディア、およびそのアプリの識別子を当社に送信します。

**当社が収集しない情報。** 当社は広告、分析、ソーシャルメディアのトラッキングツールを使用せず、広告プロフィールを構築せず、正確な位置情報も収集しません。当社はあなたに機密情報の提供を求めませんが、あなたが公開を選択した場合、投稿にそれが明らかになることがあります。

## 10. アカウントの削除

niceideas のアカウントは、あなたの NiceMatrix ID を削除することで削除されます。

1. 削除を依頼すると、あなたの niceideas プロフィールと投稿は直ちに非公開になります。
2. NiceMatrix ID のクーリングオフ期間（現在は15日間）中に取り消した場合、すべてが同じリンクで元に戻ります。
3. クーリングオフ期間が終了すると、当社は最大14日間のバックアップサイクルを除き、それ以上の保持期間なしに、あなたのプロフィール、投稿、以前のバージョン、メディア、コメント、いいね、フォローを永久に削除します。

個々の投稿はいつでも削除することができ、それ以外のものの削除については当社にご連絡ください。
