范围（和现有 /admin 的差别）
· 现在只有一页：举报列表 + 按链接查帖子。改成左侧导航的多页后台。
· 举报队列：同一对象的举报合并；右侧看详情、处理，不用离开列表；常用原因一键填入。
· 评论：可隐藏/删除；匿名评论者可按访客标识或 IP 哈希封禁（计划 §16.2 已定，后端已有，界面未做）。
· 帖子：下架/恢复、改评论设置（所有人/仅登录/关闭），带处置记录。
· 封禁：列表、到期时间、解除。
· 用户：按 handle 查用户，看帖子数、被举报次数；本期不做封号（账号属于 NiceMatrix ID）。
· 接入应用：显示 NiceMatrix 目录里的状态，可在本站单独停用某个应用。
· 审计日志：所有处置，可按操作和处理人筛选。

不做：运营数据看板、内容推荐位、批量操作（以后有需要再加）。
技术：服务端直出，不开 JS 也能用；J/K 快捷键是增强。后台文案同样 40 种语言。
