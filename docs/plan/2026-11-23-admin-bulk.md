# 后台批量操作（v1.0.96）— 方案

状态：Xianglin 2026-11-23 确认（13:54 范围、评论页一起做；14:06 设计稿通过，表格变紧凑、尽量不换行，栏下灰色说明不要）。设计稿：`docs/design/mockups/admin/bulk/`。

## 1. 范围
- 帖子列表 `/admin/posts`：下架、恢复、收窄可见范围（选目标值：有链接的人 / 仅关注者 / 仅朋友 / 仅自己可见）。
- 评论列表 `/admin/comments`：隐藏、恢复。批量隐藏**不带封禁**，封禁只在单条操作里做。
- 只作用于当前页勾选的条目（每页 30 条；服务端上限 50），不做"选中筛选结果的全部"。
- 只读成员（viewer）没有勾选列和批量栏，服务端也拒绝。

## 2. 规则
- 一个原因（必填）用于所有选中条目；每条各走单条操作（`admin-actions.ts runAdminAction`）：各自事务、各自一条审计记录，锁内复查与单条操作相同。
- 不适用的条目跳过，不算失败：已下架的不再下架，只有已下架的能恢复，可见范围只能收窄（`isNarrower`），只有可见的评论能隐藏，只有已隐藏的能恢复。
- 部分成功：结果提示"{操作}：成功 N 条 · 跳过 N 条"，有失败时追加"失败 N 条"（`?n=bulk&op=…&ok=…&skip=…&fail=…`，数字夹在 0–50）。成功 0 条或有失败时提示为红色。
- 请求本身无效（未知操作、没有原因、没选、超过上限、目标可见范围不合法）→ "操作失败"，什么都不做。

## 3. 界面
- 每行前一个勾选框（`form="ad-bulk"`，表格行里已有各自的弹出表单，所以批量表单在表格外、勾选框按 id 加入）。
- 表格卡片顶部一条批量栏：全选本页 + "已选 N / 总数"（JS）、操作、"改为"（仅收窄可见范围时，JS）、原因、"应用到 N 条"（下架 / 隐藏为红色）、取消选择。桌面吸顶，手机吸底。
- 不开 JS：逐个勾选、选操作、填原因、提交都能用；选中行和批量栏的浅紫底色用 CSS `:has()`。
- 表格变紧凑：单元格左右间距 0.75rem（卡片边缘仍 1.125rem）；作者、来源、状态、可见范围、发布时间、数字列不换行。

## 4. 代码
- `src/server/admin/bulk-actions.ts`：校验、去重、逐条判断是否适用 + 调用单条操作、计数。
- `src/server/admin-ui/admin-routes.ts`：`action=bulk` 分支，带计数跳回。
- `src/server/admin-ui/bulk-bar.ts`：勾选列 + 批量栏（`bulkTable`）、结果提示（`listNotice`）。
- `public/scripts/admin.js`：全选、计数、按钮文字 / 颜色 / 可用状态、"改为"的显隐。
- `public/styles/admin.css`：紧凑表格、批量栏、手机布局。
- 翻译：`admin.bulk.*` 10 个键，40 种语言。

## 5. 帖子列表收列（方案 A，Xianglin 14:41 选定）
- 改动前帖子列表在 1280 px 下 32 种语言超出右边；只调间距后仍有 28 种。
- 作者、来源、发布时间、点赞数、评论数移到标题下两行小字：「@作者 · 来源 · 时间」「♥ 点赞 · 💬 评论 · /p/代码 · 类型」（图标带隐藏文字）。表格只剩：勾选、帖子、状态、可见范围、操作。
- 手机上状态筛选条过长时左右滑动，不再撑宽页面。
- 结果：40 种语言在 1280 px 和 390 px 下都不超出。平板宽度（800–1024 px）个别长语言仍略超（如法语 1024 px 超 51 px），比改动前小得多。
