# 有链接的人可见（v1.0.94）— 方案

状态：Xianglin 2026-11-23 11:55 确认，全部按建议（叫法「有链接的人」、未登录可看、显示链接预览、不进作者自己的首页时间线），并追加 §8 管理后台修改可见范围；12:01 追加 m.nicematrix.com 后台直接修改（§6）。在 v1.0.93「仅关注者 / 仅朋友」（`docs/plan/2026-11-10-audience-visibility.md`）的基础上新增第五种可见范围。

## 1. 规则
| 值 | 谁能看 | 出现在哪里 |
|---|---|---|
| `link`（新） | 拿到链接的任何人，**包括没登录、没账号的人** | 只有作者自己的主页；别人那里都不出现 |

- 叫法（zh-Hans）：选项「有链接的人」，说明「拿到链接的人都能看，包括没有账号的人；不在你的主页、时间线、发现和搜索中显示」。英文 "Anyone with the link"。图标用现有的链接图标。
- 选项顺序：公开 → 有链接的人 → 仅关注者 → 仅朋友 → 仅自己可见。
- 链接本身就是钥匙：帖子地址是 14 位随机字符（约 70 位随机性），猜不出来，也没法逐个试出来。站外链接不带来源地址（已有 `Referrer-Policy` + `noreferrer`），链接不会因为点了站外链接而泄露。

## 2. 在哪里出现
- **帖子页：**拿到链接的人都能看全文，顶部提示「这条帖子不公开列出，只有拿到链接的人能看到」（和其他范围的提示同一样式）。
- **作者自己的主页：**列出，卡片上标「🔗 有链接的人」，帖子数计入。
- **别人看作者主页：**不列出，帖子数也不计入。
- **作者自己的首页时间线：**不出现（和「仅自己可见」一样：时间线只放会推给别人的帖子）。
- **不出现：**关注者的首页时间线、发现、搜索、推荐作者、别人的「回复」页、引用列表、搜索引擎（noindex）。
- **收藏页：**别人收藏过的，在他自己的收藏页里照常出现（他已经拿到过链接）。
- **通知：**作者照常收到点赞、评论通知；在帖子下评论过的人照常收到回复通知。用「有链接的人」发的引用帖，**不**通知被引用的人（不然等于把链接发给了他）。

## 3. 互动
- 能看的人可以点赞、评论、收藏、分享链接、举报（和现在未登录用户在公开帖子上能做的一样）。
- 不能转发、不能引用：转发和引用会把帖子推进别人的时间线，违背「只能点链接看」。按钮不出现，接口拒绝。
- 改成其他范围后，已有的收藏 / 评论按新范围重新判断，和现在一样。

## 4. 链接预览
- 在微信、iMessage、Telegram 等地方发链接时，**显示**标题、摘要和封面卡片（分享卡片图照常生成），这是通过 App 分享的主要场景。
- 页面仍然不收录（`noindex`）。
- 代价：聊天软件会自己缓存预览；帖子改成私密后，已经发出去的预览卡片可能还会留一段时间。会写进条款。

## 5. 媒体
- 和其他不公开范围一样放在**私有存储**，经 `/p/{slug}/media/{key}` 检查后返回；对「有链接的人」的帖子，未登录访客也放行。`Cache-Control: private`，不经 CDN。
- 好处：「只有公开帖子进公开存储」这条规则不变，审核、下架、删号、媒体搬移的逻辑都不用动，风险最小。
- 代价：这类帖子的图片和音频由站点直接返回，不走 CDN，打开会比公开帖子稍慢。以后访问量大了再考虑走 CDN。
- 分享卡片图改为从私有存储读取，同样 `private`，不进 CDN 缓存。保险起见，从「有链接的人」改成更小范围时，也清一次卡片图的 CDN 缓存。
- 公开 ↔ 有链接的人：媒体在两个存储之间移动，和现在「公开 ↔ 不公开」一样；和其他不公开范围之间切换不移动文件。

## 6. 设置入口
- **发帖框**的「谁可以看」和**作者「⋯」菜单**的「谁可以看」各加一项，不开 JS 也能用。
- **乐趣记事本 / NiceMatrix 后端（合同只加字段，旧客户端不受影响；Xianglin 12:01 追加：m.nicematrix.com 后台要能直接改）：**
  - `visibility` 继续只返回 `public | private`，「有链接的人」算 `private`（不公开）；`audience` 返回 `link`；`visibility_changed` 事件带上它。
  - `PATCH` 新增 `audience`（五种值，和 `visibility` 一起发时以 `audience` 为准），后台管理页和以后的 App 都用它；只发 `visibility` 的旧客户端照旧：对不公开的帖子发 `private` 保持原样。
  - 创建分享（`POST /posts`）也可以带 `audience`，不带就是公开；同一个分享重复请求不改。这样以后 App 分享时加「有链接的人」选项，NiceIdeas 不用再改。
  - 后台要做的（另一个项目，记在 `docs/plan/cross-agent-requests.md` #7）：分享列表显示 `audience`，管理员只能改小，调 `PATCH` 时带 `narrowOnly: true`，后台自己记审计；NiceIdeas 不回发事件。

## 7. 实现
- **迁移 `0027_post_link_visibility`：**`post.visibility` 的取值检查放宽到五种，不改数据。回滚时「有链接的人」的帖子变成「仅自己可见」（看到的人只少不多）。
- **规则仍然集中在两处：**
  - `posts/visibility.ts` `canSee`：`link` 对所有人返回 true。
  - `db/repos/post-access.ts` `visibleTo`：列表默认不含 `link`（作者本人看自己主页时含）；新增选项给收藏、回复通知用（看的人已经拿到过链接）。
  - 「是否列出 / 是否进公开存储」的判断不变：仍然只有 `public`。
- **其他改动：**单个帖子页（预览卡片 + noindex）、媒体路由（未登录放行）、分享卡片图路由、可见范围切换（清缓存）、可见范围的图标和文字、乐趣记事本 PATCH 兼容。
- **测试：**`link` × 作者 / 关注者 / 陌生人 / 未登录：帖子页、媒体、卡片图、点赞、评论、收藏、举报、时间线、主页、帖子数、收藏页、通知、发现、搜索、回复页、引用列表；转发和引用被拒绝；切换范围时媒体移动和缓存清理；乐趣记事本 DTO 和 PATCH 兼容；回滚迁移。浏览器检查发帖框、菜单、帖子页提示、卡片标记：手机和电脑，浅色和深色。
- **多语言：**新增词条，40 种语言同一个提交里全部翻译。
- **条款和隐私政策：**条款要点和 4.5、隐私政策「不公开的帖子」一段加上这一项，并改掉「不公开的帖子不会出现在链接预览中」这句话（这类帖子有预览）；写明拿到链接的人可以继续转发链接。40 种语言，生效日期更新。

## 8. 管理后台修改可见范围（Xianglin 11:55 追加）
- 帖子列表新增「可见范围」一列（图标 + 文字）。
- 正常状态的帖子，「可见范围」一列的值就是按钮，点开选新的范围，必须填原因，和其他管理操作一样记入审计日志（记录改前和改后的值）。已下架、已删除的帖子不能改（和作者自己改的规则一样）。
- **只能改小**（Xianglin 12:54）：公开 → 其余四种；有链接的人 → 仅自己可见；仅关注者 → 仅朋友 / 仅自己可见；仅朋友 → 仅自己可见。「有链接的人」改成仅关注者 / 仅朋友不算改小（会出现在别人的时间线里）。仅自己可见的帖子没有可选项，只显示当前值。服务端同样检查，加锁后再查一次。m.nicematrix.com 后台调用 `PATCH` 时带 `narrowOnly: true`，NiceIdeas 同样拒绝改大。
- 走和作者自己修改同一套流程（`posts/set-visibility.ts`）：媒体搬移、CDN 清理都一样；乐趣记事本分享的帖子同样发 `visibility_changed` 事件，App 里显示同样的状态。
- 只有能执行管理操作的成员能改，只读成员只能看。
- 迁移 0027 同时允许审计日志的新操作类型 `visibility`。
