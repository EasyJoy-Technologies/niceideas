# 点赞 / 评论归属账号 + 收藏 — 方案与实现记录

日期：2026-10-26 · 版本：v1.0.79 · 决定：Xianglin 22:36（登录后点赞、评论按账号，未登录才匿名）、22:53（点赞和评论主要属于账号，
匿名只是暂时支持，以后会关闭；新增收藏：私有，可查看自己的收藏，帖子显示收藏人数）。

## 1. 点赞
- 登录用户：`post_like` / `comment_like` 写 `liker_key = u:<userId>`、`user_id`；任何浏览器里都显示"已赞"，作者通知里显示点赞人。
- 未登录：照旧按浏览器（`v:<hash>`）。
- 衔接：同一浏览器登录前的匿名点赞也算本人已赞（不重复计数）；取消时两条一起删除。
- 限流：沿用每 IP 每小时上限。

## 2. 评论
- 登录用户：`author_id` = 本人，显示账号名称和头像（无头像显示首字），名称链接到主页（中国大陆不链接）；
  不需要工作量证明，不填昵称；`visitor_key` / `ip_hash` 照存（审核封禁按浏览器 / IP）。
- "仅登录用户可评论"的帖子：登录用户可评论，访客 403。
- 限流：登录用户每账号 10 分钟 10 条（`RATE_USER_COMMENTS_PER_10MIN`），另受每 IP 上限。
- 未登录：照旧匿名（昵称可选 + 工作量证明）。匿名路径集中在 `createComment` 的 `!viewer` 分支与 `likerKeysOf`，以后关闭匿名只改这里和页面上的访客表单。

## 3. 收藏（新）
- 数据：`post_bookmark(user_id, post_id, created_at)` + `post.bookmark_count`（迁移 0023）；`created_at` 取毫秒精度，翻页游标不漏行。
- 接口：`POST / DELETE /api/v1/p/{slug}/bookmark`（同源、封禁检查、幂等；未登录 401 `auth.required`；与点赞同属"帖子页互动"，大陆可用）。
  API 帖子对象新增 `bookmarkCount`。
- 页面：帖子页操作栏 + 手机底栏 + 时间线卡片显示收藏按钮和人数；已收藏为主色实心。未登录点击 → 登录后回到原页；大陆访客只显示人数。
  私有帖子不显示收藏（与点赞相同）。
- 我的收藏 `/bookmarks`：仅本人、noindex、按收藏时间倒序、20 条一页；只列出当前可见的帖子（下线 / 设为私有的暂不显示，恢复后重新出现）。
  入口：左侧导航、账号菜单（手机在头像菜单里）。大陆 451（站点页面）。
- 隐私：谁收藏了什么从不公开；不发通知。隐私政策 40 种语言在"互动"段落补充一句。

## 4. 注销账号
- 删除资料时级联删除本人的点赞、评论（及他人对其评论的回复）、收藏；之后按实际行数重算受影响帖子的点赞 / 评论 / 收藏数和评论点赞数
  （原来级联删除不会更新计数）。

## 5. 发现、不在本次范围
- 时间线翻页游标只带毫秒，同一毫秒内发布的两条帖子恰好跨页时，后一条可能漏掉（极少见，现有问题）。
