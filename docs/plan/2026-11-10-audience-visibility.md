# 仅关注者可见 / 仅朋友可见（v1.0.93）— 方案

状态：Xianglin 2026-11-10 确认。15:55 定了不做关注审批、无权限的人看上锁页（B）、乐趣记事本这期不改；16:42 说"直接改完剩下的再部署"。在 v1.0.75「仅自己可见」（`docs/plan/2026-10-26-private-theme-guidelines.md` C）的基础上扩展。

## 1. 四种可见范围
| 值 | 谁能看 | 页面上的叫法（zh-Hans） |
|---|---|---|
| `public` | 所有人 | 公开 |
| `followers` | 作者本人 + 关注了作者的人 | 仅关注者可见 |
| `friends` | 作者本人 + 和作者互相关注的人 | 仅朋友可见（互相关注） |
| `private` | 作者本人 | 仅自己可见 |

- 每次打开时按当前关注关系判断：取消关注或不再互关，马上就看不到了。
- 关注不需要审批，所以「仅关注者可见」任何人关注后都能看，这一点已向 Xianglin 说明并获认可。

## 2. 没有权限的人
- 帖子页显示上锁页（Xianglin 选 B）：作者头像、名字，提示「仅作者的关注者可见，关注后即可查看」或「仅作者互相关注的朋友可见」。
  - 已登录：显示关注按钮；已经关注但不是互关时，提示需要对方也关注你。
  - 未登录：显示「登录」，登录后回到这个帖子。
  - 中国大陆模式：只显示文字，不提供登录和关注。
- HTTP 403，页面不收录（noindex），没有分享卡片，不显示帖子内容、媒体和评论。
- 点赞、评论、举报、媒体地址、分享卡片图对这些人一律返回 404，和不存在一样。
- 帖子被删除或被移除后，和公开帖子一样显示 410。

## 3. 在哪里出现
- **帖子页：**有权限的人看到全文，顶部提示「仅关注者可见 / 仅朋友可见」（和「仅自己可见」的提示同一样式）。
- **首页时间线：**关注的人发的帖子按权限出现；自己的这两类帖子也出现；「仅自己可见」仍然不出现，和现在一样。
- **个人主页：**帖子列表和帖子数都按看的人的权限计算。看自己的主页时什么都能看到，和现在一样。
- **收藏页、通知（回复、引用）：**按看的人的权限过滤。
- **个人主页的「回复」页：**只列公开帖子下的评论（帖子封面图来自公开存储），和现在一样。
- **不出现：**发现页、搜索、推荐作者、转发、引用、分享卡片图、搜索引擎。
- **卡片标记：**时间线卡片的时间后面显示图标和文字（👥 仅关注者 / ✓ 仅朋友），和现有的 🔒 仅自己同一样式。

## 4. 互动
- 有权限的人可以点赞、评论、收藏、分享链接、举报。不能转发、不能引用，按钮不出现，接口拒绝。
- 已有的转发和引用保留在数据里但不显示；帖子改回公开后恢复显示，和「仅自己可见」一样。

## 5. 媒体
- 和「仅自己可见」一样放在私有存储，不经过 CDN。
- 访问 `/p/{slug}/media/{key}` 时检查看的人有没有权限：响应头 `Cache-Control: private`，`Vary: Cookie`。
- 公开改成这两种时，媒体移回私有存储，并清除 CDN 缓存；这两种之间、或和「仅自己可见」之间切换，不需要移动文件。

## 6. 设置入口
- **发帖框：**新增可见范围选择，默认公开，在「发布」按钮旁边。不开 JS 时也能用。编辑帖子时不显示。
- **作者「⋯」菜单：**原来的「设为仅自己可见 / 设为公开」改成「可见范围」子菜单，列出 4 个选项，当前那个打勾；不开 JS 时也能用。
- **乐趣记事本 / NiceMatrix 后端（不改合同，只做兼容）：**
  - `PATCH` 仍然只接受 `public | private`。
  - `visibility` 字段继续只返回 `public | private`：这两种新范围算作 `private`，意思是「不公开」。
  - 新增字段 `audience` 返回实际的四种值，`visibility_changed` 事件也带上这个字段。旧客户端不需要任何改动。

## 7. 实现
- **迁移 `0026_post_audience`：**把 `post.visibility` 的取值检查放宽到四种值，只放宽检查、不改数据。可以回滚（down）。
- **规则集中在两处，不各写一份：**
  - `posts/visibility.ts`：单个帖子的权限判断，`canSee`，需要时才查关注关系。
  - `db/repos/post-access.ts`：列表查询用的 SQL 条件。时间线、主页、收藏、回复、通知都用它。
  - 判断「公开 / 进公开存储」的地方（媒体、审核、推送、删号）规则不变：只有 `public` 进公开存储。
- **发帖：**`createPost` 新增 `visibility` 参数；不是公开时不把媒体移到公开存储。
- **测试：**
  - 每种范围 × 看的人（作者、关注者、互关、陌生人、未登录）：帖子页、上锁页、媒体、点赞、评论、时间线、主页、帖子数、收藏、回复、通知、发现、搜索。
  - 转发、引用、分享卡片图被拒绝。
  - 取消关注后立即失去权限。
  - 可见范围在公开和非公开之间切换时，媒体在两个存储之间移动。
  - 乐趣记事本 DTO 和事件的兼容。
  - 发帖时选择可见范围。
  - 浏览器检查发帖框、菜单、上锁页、卡片标记：手机和电脑，浅色和深色。
- **多语言：**新增词条，40 种语言同一个提交里全部翻译。
- **条款和隐私政策：**把「默认公开，可设为仅自己可见」改成包括这两种新范围，40 种语言都改，生效日期更新。
