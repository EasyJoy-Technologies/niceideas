# v1.0.41 — 2026-10-21

## Added
- Web moderation console `/admin` (moderators listed in `ADMIN_USER_IDS` only; everyone else gets 404, signed-out → sign-in; 451 in mainland China):
  - open reports queue (reason, details, reported post / comment) with "hide comment" / "remove post" (resolves the report) and "dismiss";
  - post lookup by link or code with remove / restore.
  - Every action requires a reason and is audited in `moderation_action` (same services as the moderation CLI).
- Account menu shows "Moderation" for moderators.
- 19 i18n keys × 40 locales.
