# v1.0.54 — 2026-10-22

## Changes
- Compose box v2 (docs/design/mockups/v4/compose-v2.html): one toolbar row from the card's left edge — image, audio | bold, italic, link, lists, checklist (article: heading too) | "…" (subheading, numbered list, quote, strikethrough, inline code, code block, divider) | Short / Article toggle | Post.
- Short posts: editor at least 5 lines, growing with content; images as thumbnails and audio as a player bar under the text; 500-character limit with a counter near the limit. They stay "short" in the feed, which now shows the text, then the image thumbnails (lightbox) and audio.
- Articles: title row, larger editor (≥ 420px); images and audio are inserted at the cursor and published in place.
- Rich editor: Tiptap (MIT), bundled by scripts/build-client.mjs into /scripts/compose.js and loaded only on the signed-in home page. The editor JSON is converted to Markdown / to-do / image / audio blocks on the server (escaped, links limited to http(s) / mailto, rendered through the existing sanitizer).
- Without JS: plain text, image and audio file inputs, and the Short / Article toggle still publish.
- Audio upload from the web (up to 10 per post, existing 150 MB per-file limit).
- i18n: 25 new compose keys in all 40 languages; `compose.imagesChosen` / `compose.titlePlaceholder` removed.
