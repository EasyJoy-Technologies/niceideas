## Changes
- **"From <app>" is shown only for apps that are turned on.**
  - Our own apps are the NiceMatrix product groups, by the `sourceApp.key` sent with each share. A new key is added to the list on its first share, with the label off.
  - The names sent with each new share keep the list's names up to date. The label setting, website and icon are never changed by a share.
  - Third-party apps (open API) get a new `show_badge` flag, off by default. This includes apps already registered, so their posts stop showing "From …" until it is turned on (staging: OmniFire).
- **New admin page Settings → Apps (`/admin/apps`).**
  - "Our apps" table: icon, name (the page language's name: Simplified / Traditional Chinese where sent, English otherwise), key, website, label shown or not, number of posts. Edit form: show the label (checkbox), website (https), icon (https URL or `/brand/sources/…`).
  - "Third-party apps" table: name, logo and website from the NiceMatrix app directory, label shown or not, number of posts, and a Show / Hide button.
  - Only admins can change these settings. Moderators and viewers can only see the page.
  - Each change is recorded in the audit log as "Changed app settings", with the app and its new state. It applies right away in the process that made it; other processes pick it up within a minute (the source cache refreshes every minute).
- Website and icon of our apps now live in the database, set on the Apps page. The setting `SOURCE_NICENOTE_URL` is no longer read, and v1.0.90's `SOURCE_NICERECORDER_URL` / `SOURCE_NICELIST_URL` are gone. The starting values are the same as before.
- Admin post list and overview: our apps come from the Apps list, in the order they were added. The filter value is now `?src=app:<key>`. An app's own name is shown in the admin even while its label is off on the site.
- i18n: 21 new admin keys in all 40 locales. Removed `common.brand.*`, which is now unused because names come from the Apps list.

## Database migrations
- `0025_source_apps` replaces v1.0.90's `0025_post_source_app`, which was never applied anywhere:
  - Two new post columns, `post.source_app_key` and `post.source_app_names`. Shares made before this release get NiceNote filled in.
  - A new `source_app` table, seeded with NiceNote, NiceRecorder and NiceList, all shown. Each has its icon under `/brand/sources/` and its website (enp / er / ec.ej-mobile.cn).
  - A new `api_client.show_badge` column, `false` by default.
  - A new audit log action, `moderation_action` `app_settings`.
  - Rollback: run the migration's `down`.
