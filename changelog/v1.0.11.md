# v1.0.11 — 2026-10-20

## Fixes
- Standalone build: removed the `outputFileTracingExcludes` added in v1.0.9. Its `./src/**` pattern also dropped `src/` folders inside dependencies (e.g. `debug/src`), which broke `file-type` / `music-metadata` at runtime, so media upload failed. Stray repo files copied by the tracer are now removed by the deploy script instead.
- Server CLIs (`dist/*.mjs`): `file-type` and `music-metadata` are now kept third-party, like `sharp`, because they load `strtok3` through a runtime dynamic import that a bundle cannot satisfy. The deploy script links them from the release's pnpm store into `dist/node_modules` and checks they import before switching releases.
