# v1.0.56 — 2026-10-22

## Fixed
- Language menu: a choice is now remembered. Links go through `/api/web/lang?hl=…&next=…`, which sets the `ni_locale` cookie (1 year) and returns to the same page, so later pages and menus keep the chosen language. `?hl=` on a page URL still shows that one page in a language without a cookie. `next` accepts same-site paths only.
- Compose "…" menu: on wide screens it is hidden for short posts (every item there is article- or phone-only, so it opened empty). Phones keep it (italic, link, checklist). Switching mode closes an open menu.
- Translations: native-level wording fixes in ar, el, es, fr, ha, hi, bn, ne, it, ja, ms, pt-BR, sw (compose and footer menu).
