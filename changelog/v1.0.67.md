# v1.0.67 — 2026-10-25

Security fixes from the review `docs/ops/2026-10-25-security-review.md`.

## Fixed
- Redirect targets taken from user input (`/auth/sign-in?next=`, follow, language, theme, delete and admin forms) go through one check (`src/server/http/safe-path.ts`): paths with whitespace, control characters or backslashes become "/". Before, `/<tab>/evil.example` passed the sign-in check and browsers turned it into a redirect to another site.

## Added
- `Strict-Transport-Security: max-age=31536000` and `X-Content-Type-Options: nosniff` on every response.
- nginx (applied separately, needs approval): only Cloudflare addresses may reach the origin (direct requests 403), IPv6 Cloudflare ranges trusted for the visitor address; staging gets the same real-IP setup as production.
