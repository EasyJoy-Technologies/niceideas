# v1.0.0 — 2026-10-19

## Changes
- Project skeleton: Next.js 16 (App Router, standalone), TypeScript strict, Tailwind v4 with DESIGN.md tokens, self-hosted Inter.
- i18n framework: next-intl without URL prefixes; 40 locales; cookie → profile → Accept-Language negotiation (es-MX → es, zh-TW → zh-Hant, pt-AO → pt-PT); RTL for ar/fa/he/ur.
- Translation tooling: `scripts/i18n-merge.mjs` (all-locale batches only) and `scripts/check-i18n.mjs` (key parity, empty, untranslated, ICU placeholder parity).
- Version single source (`package.json`) exposed at `GET /api/v1/meta` and in the footer; `scripts/version-bump.mjs`.
- Structure gate (≤300 lines, no CJK literals in source) and ESLint `react/jsx-no-literals`.
- Placeholder landing, not-found and error screens; CI workflow.
