# v1.0.58 — 2026-10-22

## Added
- Dark mode (front end): theme menu (System / Light / Dark) in the header, right column, footers and information-page header. Choice stored in the `ni_theme` cookie (`/api/web/theme`, works without JS); the server picks `dark.css` (always, never, or by `prefers-color-scheme`) — no inline script, no flash. Dark lockup is now transparent; `theme-color` follows the theme. Page cache keyed by theme.
- Phone bottom tab bar on feed pages (approved v2 design): Home / Discover / + / Notifications / Profile; signed out: Discover / Sign in (no compose button). "+" opens the compose card as a bottom sheet (`/#compose`, CSS :target, no JS needed); compose errors return to the sheet.
- Header search button: the field opens in a row under the header (no JS: <details>).
- Phone header shows the mark + "niceideas" (mark only below 360 px).

## Changed
- Information pages: page links in a header hamburger on phones; footer © only.
- All hard-coded colours moved to tokens (`tokens.css`, overridden by `dark.css`).
- Feed "Images" tab removed (old `?tab=images` links show "All").
- New i18n keys `theme.*`, `nav.signIn|compose|me` in 40 languages.
