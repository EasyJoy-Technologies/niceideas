# v1.0.17 — 2026-10-20

## Fixes
- Proxy rewrites (mainland-China 451 page and `/@handle` → `/u/<handle>`) now target the server's own origin. Behind nginx the request URL carries the public `https` scheme, so Next treated the target as third-party and tried to proxy to `https://localhost:3110` (plain HTTP), which failed:
  - profile pages answered 500;
  - mainland-China visitors of site pages (home, discover, information pages) got the normal page instead of the 451 page. Direct requests to the app port were unaffected, which is why earlier checks passed.
