# v1.0.79 — 2026-10-26

Likes and comments belong to the signed-in account; bookmarks (plan `docs/plan/2026-10-26-account-interactions-bookmarks.md`; Xianglin 2026-10-26 22:36 / 22:53: interactions are the account's, anonymous is temporary; bookmarks private, count public).

## Changed
- Likes while signed in are the account's (`u:<userId>`): liked in every browser, the author's notification names the person. A guest like given earlier in the same browser counts as the account's (no double count; unliking removes both). Guests still like per browser.
- Comments while signed in are the account's: no nickname or proof of work, shown with the profile's name and avatar (initial when none), name linked to the profile (not in mainland China); "signed-in members only" posts accept them. Own rate limit `RATE_USER_COMMENTS_PER_10MIN` (10) plus the address limits. Guests still comment anonymously.
- Account deletion recounts likes, comments and bookmarks of every post (and comment likes) the account's removed rows were part of (cascades used to leave the counters too high).

## Added
- Bookmarks: button with the public count on post pages (action row + phone bar) and feed cards; filled when saved. `POST / DELETE /api/v1/p/{slug}/bookmark` (signed in; guests 401 `auth.required` → sign-in and back; open in mainland China like likes). No bookmarks on private posts; nobody is notified; who saved a post is never shown.
- `/bookmarks` ("Bookmarks"): the user's saved posts, most recently saved first, 20 per page; only posts visible now (offline / private ones come back when they are back). Linked from the left navigation and the account menu. noindex; 451 in mainland China.
- API post object: `bookmarkCount`.
- Privacy policy (40 locales), "Interactions": bookmarks are private, only the count is public, removed with the account.
- UI texts (40 locales): `share.action.bookmark`, `bookmarks.title`, `bookmarks.empty`, `share.comments.asUser`.
