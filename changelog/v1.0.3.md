# v1.0.3 — 2026-10-19

## Changes
- Media pipeline (plan §6/§11): uploads streamed to a private temp file with sha256 + size limit; type detected from file header (jpeg/png/webp/gif/avif; mp3/m4a/aac/ogg/opus/webm/wav); SVG/HEIC/other rejected.
- Images: EXIF orientation applied, all metadata (EXIF/GPS) stripped, webp 480/960/1600 (no upscaling) + jpeg (png when transparent) fallback; pixel limit; max 2 concurrent decodes.
- Audio: duration probe, video tracks refused, max length; original stored.
- Per-owner dedupe by sha256, per-user quota, concurrent-duplicate cleanup.
- Storage drivers: local (dev/test) and S3/R2; private bucket for all renditions, public bucket only for live-post media (projection + withdrawal helpers).
- `POST /api/v1/media` (raw body + `X-Content-SHA256`), dev-only `/media-local` server.
