# v1.0.78 — 2026-10-26

App WebViews open NiceIdeas signed in as their user: one-time sign-in tickets (contract nicematrix-backend `docs/integration/niceideas-share.md` §10.2–10.4; plan `docs/plan/2026-10-26-app-sign-in-ticket.md`; Xianglin 2026-10-26 21:47, mainland China included).

## Added
- `POST /api/internal/v1/nicenote/web-tickets` (signed source call): prepares the profile like a share (created + registered on first contact, follows NiceMatrix), returns `{ ticket, expiresAt, exchangeUrl }`; 256-bit ticket, only its SHA-256 stored, 60 s, single use; account being deleted → 409 `user.deleting`.
- `POST /auth/app-ticket`: the app's WebView redeems the ticket (form body, also without `Content-Type`) and lands on `next`, always 303 + no-store. Same user's live session kept; any other session ended and a new app session started; failed exchange ends the current session; other sites' submissions (`Sec-Fetch-Site` cross-site / same-site, foreign `Origin`) change nothing. Logs only outcome and header categories.
- App sessions (`web_session.source = 'app'`): "Sign out" ends only the NiceIdeas session and returns home (no NiceMatrix sign-out).
- Mainland China: the exchange is open (access class `app_sign_in`); post pages there now know the signed-in viewer, so authors see their own private posts. Restricted chrome unchanged (no account menu, notifications, navigation); the author's menu has no Edit there. Every other page stays 451.
- Daily maintenance removes expired tickets.

## Fixed
- Redirect targets with non-ASCII characters (e.g. `next=/search?q=中文`) are percent-encoded instead of failing with 500 (sign-in, language / theme switches, ticket exchange).

## Changed (internal)
- Profile preparation of source calls shared by share creation and tickets (`src/server/nicenote/source-author.ts`); 303 helper `src/server/auth/web/redirect.ts`; session / ticket tables in `src/server/db/schema-auth.ts`.

## Known gap (not in this release)
- Likes and comments on the web are not tied to the signed-in user (likes per browser, comments anonymous), for web and app sessions alike.
