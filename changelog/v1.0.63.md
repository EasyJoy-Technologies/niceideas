# v1.0.63 — 2026-10-24

## Added
- NiceNote sharing through the NiceMatrix backend (contract nicematrix-backend `docs/integration/niceideas-share.md` v1, phase S1): signed source API `/api/internal/v1/nicenote/posts` (create idempotent by share id, push content ordered by cloud revision, settings, delete, get). Service-to-service `X-NM-*` HMAC signature identical to the backend's (±300 s, one-time nonces).
- NiceNote documents rendered structurally (rich lines and runs, lists by indent, quotes, headings one level down, todo, media by ref); placeholders for media still processing or unavailable; "Getting this post ready" page for a just-created share (noindex, not listed).
- Media of shares stored per owner by NiceNote ref; missing ones queued with their signed grant (fetching arrives with the worker in v1.0.64). Grants only accepted under `NICEMATRIX_API_URL`.
- Delete on the web for every post (web, NiceNote, third-party apps): "⋯" menu on the post page and on the author's own cards, inline confirmation, works without JS. NiceNote shares tell the backend (`unpublished`, queued).
- Profile follow rules for web sign-in, share requests and the new account event `profile_updated`: handle follows the NiceMatrix username, display name follows unless changed on NiceIdeas, avatar follows.
- Outbox for backend notifications (user registration, post events) — delivered by the worker in v1.0.64.
- `scripts/nicenote-smoke.ts`: signed smoke check of a deployed source API.

## Changed
- User-facing wording "withdraw" → "delete" for posts (status page, admin, About, Help, Terms §§ summary/4.3/5.5/9.2/9.4, Privacy summary/retention/rights) in 40 languages; Terms and Privacy effective date 2026-10-24.
- Page cache keys include the post's version: edits and deletions show on the next request.
- Admin: NiceNote shares counted by app region in "posts by source"; posts filter accepts `preparing`.
- Internal publishing tool posts are NiceIdeas (web-source) posts.

## Removed
- NiceNote client-token publishing (`FIRST_PARTY_*`): `/api/v1/*` accepts only third-party-app tokens; NiceNote tokens get 401 `auth.audience_not_accepted`. `/api/v1/me/sources` removed.
- Per-user media quota (5 GB) and `media.quota_exceeded` for every source.

## Database migrations
- `0013_nicenote_share`: post status `preparing`, source `nicenote`, `share_id` / `source_revision` / `region` / `media_state`; `media.source_ref`; tables `media_job`, `outbox`, `service_nonce`; `profile.name_locked`; account event `profile_updated`.

## Deployed
- staging (t.niceideas.app) 2026-10-24; signed smoke check passed
