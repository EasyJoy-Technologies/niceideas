# v1.0.6 — 2026-10-19

## Changes
- Publishing API (plan §8, §10): `POST /api/v1/posts` (re-share returns existing link), `GET/PATCH/DELETE /api/v1/posts/{id}`, `PUT /api/v1/posts/{id}/content` (edit sync), `GET /api/v1/me/sources?source=nicenote`.
- Sync rules: same content hash → no-op; older `sourceUpdatedAt` → 409 `post.stale_update`; frozen → 409; new revision switched atomically under a row lock, link unchanged.
- Author overrides (summary / cover / kind) kept across syncs; `null` returns a field to automatic.
- Withdraw: 410-ready status `unpublished`, `purge_after = now + 30 d`, media removed from the public bucket; idempotent.
- Media of each revision projected to the public bucket before commit; media dropped by a sync withdrawn after commit.
- `Idempotency-Key` support (24 h, replay / 409 in progress / 422 reuse), concurrency-safe single publication per note, 14-char unguessable slugs.
- Per-user rate limits for posts / revisions / media uploads (429 + Retry-After); JSON bodies capped at 2 MB.
