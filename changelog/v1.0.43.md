# v1.0.43 — 2026-10-21

## Performance (pre-production capacity work)
- Multi-process server: `deploy/cluster.mjs` starts `WEB_CONCURRENCY` workers on one port (staging: 4) and replaces any worker that exits; the systemd unit runs it with MemoryMax 3G.
- Short cache for anonymous public pages (`PAGE_CACHE_SECONDS`, default 10 s): discover / home, profiles and post pages, keyed by language, region class and URL. Visitors with a session or visitor cookie always get fresh pages.
- Right-column rankings (suggested authors, popular articles) cached per process (`ASIDE_CACHE_SECONDS`, default 300 s); the viewer's own profile and followed authors are filtered out per request.
- `DB_POOL_MAX` (connections per worker, default 10).

## Fixed
- Proof-of-work challenges for anonymous comments are now single-use across all processes: spent challenges are stored in the database (migration 0008 `pow_used`) and purged by the daily maintenance job.
