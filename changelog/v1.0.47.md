# v1.0.47 — 2026-10-21

## Changed — standard third-party authorization (NiceMatrix contract 2026-10-21)
- No manual registration: third-party apps are recognised through the NiceMatrix app directory (`GET {APP_DIRECTORY_URL}/v1/oauth/apps/{clientId}`), cached ≤ 5 min; when the directory is unreachable the last known entry is used for ≤ 1 h.
- Errors: `auth.client_unknown` (not in directory), `auth.client_suspended` (suspended platform-wide), `auth.client_blocked` (blocked on NiceIdeas), `auth.insufficient_scope`, `auth.directory_unavailable` (503, first sight during an outage). `auth.client_not_allowed` is no longer returned to third-party apps.
- `api_client` (migration 0009) = directory cache (name, logo, website, directory status) + local policy (block, note, per-app hourly limit); rows are created on first sight. Posts carry source `api:<client_id>`.
- "From <app>" badge uses the directory name / logo / website only (no link when the app has no website).
- Rate limit per app × user (`RATE_APP_USER_POSTS_PER_HOUR`, default 20) in addition to per-user and per-app limits.
- `dist/clients.mjs`: list / block / unblock / limit (registration removed).
- docs/api/third-party.md: scope boundaries, error codes, rate limits, consent-page copy (zh / en).
