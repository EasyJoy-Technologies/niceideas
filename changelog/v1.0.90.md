# v1.0.90 — 2026-10-29

Source app of app shares (contract `niceideas-share.md` §3.2 `sourceApp`, NiceMatrix API 1.2.769; Xianglin 2026-10-29 14:29).

## Changes
- `POST /posts` (source API) reads `sourceApp { key, names }`. It is recorded only when it is complete and valid: the key matches `^[a-z][a-z0-9-]{0,39}$`, `names.en` is required, and `zh-Hans` / `zh-Hant` are optional. Names are trimmed, 1–100 characters, and other locale keys are ignored. Anything missing or invalid records nothing and never fails the request. The source app is set once, at creation: a repeated request for the same `shareId` does not change it.
- "From <app>" badge (post page footer, feed cards, the delete confirmation, the admin top-posts table) comes from the recorded source app. Simplified and Traditional Chinese pages show the matching name when it was sent; every other language shows English. App shares with no recorded source app show no badge.
- Our own apps: icons copied from the NiceMatrix admin app icons (64 px PNG). NiceNote keeps its existing icon. NiceRecorder links to https://er.ej-mobile.cn, NiceList to https://ec.ej-mobile.cn, NiceNote unchanged (new env `SOURCE_NICERECORDER_URL` / `SOURCE_NICELIST_URL`, defaults as above). An app key we do not know yet shows its sent name with the generic icon and no link.
- Admin, Posts: new Source column and a source filter (All sources / NiceNote / NiceRecorder / NiceList / Other apps / Web / Third-party apps, `?src=`), kept across status tabs, search and paging.
- Admin, Overview "posts by source" chart: one stack per app (NiceNote, NiceRecorder, NiceList), Other apps (only when there are any), Web and Third-party apps. The old split into NiceNote international / China is gone (`admin.source.intl` / `admin.source.cn` removed).
- i18n: `admin.source.other`, `admin.filter.allSources`, `common.brand.nicerecorder`, `common.brand.nicelist` in all 40 locales (app names are English outside Simplified / Traditional Chinese).

## Database migrations
- `0025_post_source_app`: `post.source_app_key` (text, key format check) + `post.source_app_names` (jsonb object), both null or both set. Existing app shares (`nicenote`, legacy `nicenote_intl` / `nicenote_cn`) are filled with NiceNote, because before API 1.2.769 NiceNote was the only app allowed to share. Web and third-party posts stay null. Additive; rollback = migration `down` (drops the two columns).
