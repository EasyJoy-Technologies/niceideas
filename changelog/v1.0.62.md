# v1.0.62 — 2026-10-22

## Changed
- Users without a NiceMatrix username: the handle is now their NiceMatrix (Logto) user id instead of a random `u…` string. Applies when the profile is first created (first API call from NiceNote or first web sign-in); a web sign-in without a username also replaces an old random handle with the user id. Handles that came from a username are kept. Random handles remain only as a fallback (user id unusable or already taken).

## Added
- `docs/api/nicenote.md`: NiceNote → NiceIdeas publishing contract (tokens, endpoints, document format, media, sync rules, errors, limits).
