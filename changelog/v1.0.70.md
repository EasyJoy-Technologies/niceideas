# v1.0.70 — 2026-10-26

Account deletion hardening from the sharing review (nicematrix-system reports 2026-10-25 / 2026-10-26: F02, F01, F03).
Plan: `docs/plan/2026-10-26-share-review-fixes.md` (confirmed by Xianglin 2026-10-26).

## Fixed
- F02: nothing of an account in its deletion cooling-off period goes live any more. A NiceNote share pushed during cooling-off keeps its content offline (`author_deleting`) and goes live when the deletion is cancelled; media finishing meanwhile stay private; a moderator restore keeps the post offline; the share page (also "preparing") and the share-card image answer 410 for such an account.
- Same gap on the publishing API (not in the review): creating or syncing a post during cooling-off now answers 409 `user.deleting` instead of publishing it.
- F01: an account event counts as handled only once all its steps succeeded. A failed final deletion (e.g. a storage error) answers 5xx and the backend's redelivery runs it again, instead of being treated as a duplicate with the content left online. A delivery arriving while the same event runs answers 503 `account_event.in_progress`.
- F03: after the final deletion the user is remembered for good: no profile, share, push or stored media is created for them again (409 `user.deleting`; the web sign-in shows the "account being deleted" page).
- Media moved to the public bucket ahead of a publish that then did not happen (account being deleted, refused or unchanged under the lock) go back to the private bucket at once.

## Internal
- Lock order profile → post everywhere a post can go live (`src/server/accounts/author-gate.ts`); deletion steps take the profile lock exclusively.
- Account events split: `account-events.ts` (signature, schema), `apply-account-event.ts` (claim, run, complete), `account-deletion.ts` (the three steps).
- `settlePublication` (`src/server/media/publication.ts`): after the commit, media moved but not live go back; live media not moved yet are published.
- Avatar copy stored by the worker during the final deletion is removed too.

## Data
