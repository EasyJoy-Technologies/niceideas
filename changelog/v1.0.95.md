# v1.0.95 — 2026-11-23

Admins can only narrow who can see a post, never widen it (Xianglin 2026-11-23 12:54; plan `docs/plan/2026-11-23-link-visibility.md` §8). He also asked for v1.0.94 + v1.0.95 to go to staging and production right away.

## Changes
- **Admin console (`/admin/posts`):** the Visibility form offers the current value plus the narrower ones only.
  - Narrower: public → any other; link → only me; followers → friends / only me; friends → only me.
  - Link → followers / friends is not narrower: those posts appear in timelines, link posts nowhere.
  - Only-me posts show just the value, with no form.
  - The server refuses wider values ("failed" notice, nothing audited). It checks again under the post lock, in case the author changed it meanwhile (`isNarrower`, `src/server/posts/visibility.ts`).
- **NiceNote / NiceMatrix source API:** `PATCH /posts/{id}` accepts `narrowOnly: true` for operators on the backend's admin console.
  - A wider value gets 409 `post.visibility_not_narrower`, and nothing in the request is applied.
  - Without the flag, nothing changes: the user in the app may still widen.
  - Documented in `docs/api/nicenote.md`; `docs/plan/cross-agent-requests.md` #7 updated.
