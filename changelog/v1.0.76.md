# v1.0.76 — 2026-10-26

Fix found in the v1.0.75 staging check: Cloudflare caches the media domain's 404s, so media going back to the public store (post made public again) stayed broken at the edge until that cache expired.

## Fixed
- Media returning to the public store are purged from the CDN edge in the same transaction (`queueReturningMediaPurge`): post made public again, post restored by moderation, account deletion cancelled (the last two had the same latent issue since F22).
