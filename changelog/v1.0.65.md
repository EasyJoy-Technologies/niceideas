# v1.0.65 — 2026-10-24

## Added
- Image viewer (plan `docs/plan/2026-10-24-image-viewer.md`, design `docs/design/mockups/viewer/`), on post pages and feed cards:
  - Zoom and pan: pinch / double-tap on phones; click, mouse wheel / trackpad and the zoom button on computers.
  - Swipe, arrow buttons or ← → between the images of one post or feed card, in page order, with a “2 / 4” counter; stops at the first and last image.
  - Long images (at least 3× taller than wide) open at reading width from the top and scroll down; a slim track shows the position in tall views.
  - Caption (figure caption, else image description) at the bottom, hidden while zoomed in or reading down a long image.
  - Closes with ×, Esc, a click beside the image, a downward swipe, or the phone's back button; focus returns to the image.
  - Dark backdrop in both themes; site icons and tokens; no animations with reduced motion. Right-to-left languages: the viewer's controls run left to right like its swipes; captions keep their own direction. Without JS the image link opens the image.
  - PhotoSwipe 5.4.4 (MIT) bundled into `/scripts/viewer.js`, same origin; loaded only on pages with images.
- Zoom rendition `large.webp` for new still images wider than 1600 px: at most 4096 × 4096 worth of pixels (by area, so panoramas stay tall), each side ≤ 16383 px, never upscaled, WebP quality 82 (encoder effort 2: about half the encoding time for ~5 % more bytes; a 20.7 MP photo now takes ~6.5–7 s to process, estimated ~3 s without it). Web uploads and NiceNote shares alike; animated images keep their responsive set only. The viewer downloads it only when the view needs that detail. Stored, published, withdrawn, deleted and counted in media size with the other renditions.

## Changed
- Image links carry the viewer's size and rendition list (one helper for post bodies and feed thumbnails) and point at the most detailed rendition.
- The old full-screen image box (share.js, `.ni-lb` styles) is removed.
- New labels in all 40 languages: image viewer, zoom, previous / next image, image load error.

## Database migrations
- none (`media.variants.large` is an optional JSON field; images stored before this release have none and open their 1600 px rendition)
