# v1.0.69 — 2026-10-26

Short posts with a title (decided with Xianglin 2026-10-26).

## Changed
- Short / article choice (posts that are not set to a type): the title now counts toward the 500 characters. Title + text ≤ 500, no images or audio → short; otherwise article.
- A short post that carries a title (NiceNote shares, API) shows it as the bold first line of its text: on the post page (no separate title heading), in feed cards (where the title was missing before) and in the editor. The stored document is unchanged, so share cards, the browser tab, search and admin lists still use the title.
- Editing such a post on the web keeps the bold line as text (the post then has no separate title, like web short posts). This replaces the v1.0.68 fix that kept the hidden title.

## Internal
- `src/server/documents/short-title.ts` (`withTitleInText`), used by the post page, feed cards and the edit page.
- Markdown escaping moved to `src/server/render/escape.ts` (`escapeMarkdown`), shared with the editor's Markdown output.

## Data
- No migration. Existing posts keep their type; checked on staging: 0 of 30 posts change type under the new rule. Production has no posts yet.
