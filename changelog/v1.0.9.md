# v1.0.9 — 2026-10-19

## Changes
- Post page `/p/<slug>` (plan §6, §16; approved v2 design, logo J): plain server-rendered HTML with no framework JS, readable without JS. Includes a header (logo, language menu, "Join NiceIdeas"), author block, "From NiceNote" source badge (links to `SOURCE_NICENOTE_URL` with utm), title and body, "Edited …" line, share / copy-link button, and a footer (tagline, Get NiceNote, version).
- Share cards: canonical link, description, Open Graph tags (incl. image size / alt), article times, `twitter:card=summary_large_image`, schema.org `itemprop`, plus a hidden 600×600 thumbnail as the first image for WeChat.
- Share images `/p/<slug>/og/{wide,square}.jpg`: cropped from the cover (attention crop), JPEG ≤ 300 KB, small in-process cache. Text-only posts use the brand default images.
- Status pages: 404 (not found), 410 (withdrawn / removed, noindex, no card tags), and 451 (`/status/region`).
- Mainland China: `src/proxy.ts` sends every site page to the 451 page. Post pages stay open, without any in-site navigation.
- Visitor language: `?hl=` → cookie → Accept-Language. Supports right-to-left layout. Server times are in UTC; `/scripts/share.js` re-renders them in the visitor's time zone and adds the lightbox and share button.
- Strict CSP: same-origin scripts / styles only, no inline code. Media and avatar hosts are allowed for images.
- Styles: `public/styles/{tokens,fonts,post-body,share-page}.css` are shared by the React app and the server pages.
- Tagline "Share your Nice Ideas anytime, anywhere!" (`common.tagline`). 18 new keys, all 40 locales.
- Standalone build no longer traces repo docs / tests / sources.
