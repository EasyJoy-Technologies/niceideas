# v1.0.96 — 2026-11-23

Bulk actions in the admin console's posts and comments lists (Xianglin 2026-11-23 13:11 / 13:54 / 14:06; plan `docs/plan/2026-11-23-admin-bulk.md`, approved draft `docs/design/mockups/admin/bulk/`).

## Changes
- **Admin console, posts and comments lists:** a checkbox per row and a bulk bar above the table.
  - Posts: remove, restore, narrow visibility (to a chosen value). Comments: hide, restore. Bulk hide never bans.
  - One required reason for all selected items. Each item goes through the single-item action: its own transaction and audit row.
  - Items the action does not apply to are skipped, not failed (already removed, not removed, not narrower, not visible / not hidden).
  - Result notice: "Remove post: 2 done · 1 skipped" (+ "N failed"); red when nothing was done or something failed.
  - Current page only (30 rows; server cap 50). Read-only members get no checkboxes and no bar; the server refuses them too.
  - Works without JS (checkboxes join the bar's form by id). `public/scripts/admin.js` adds select all on this page, the count, the button label / colour / disabled state and shows "Change to" only when narrowing.
  - Bar sticks to the top of the table on desktop, docks at the bottom of the screen on phones.
- **Admin tables are more compact:** cells 0.75rem apart (card edge stays 1.125rem); status, visibility, time and number columns no longer wrap.
- **Posts list has fewer columns (option A, Xianglin 14:41):** author · source · published and likes · comments · link · kind now sit in two small lines under the title; the table keeps select, post, status, visibility, action. Before, the list ran past the right edge at 1280 px in 32 of 40 languages; now in none (1280 and 390 px checked in all 40). At tablet widths (800–1024 px) a few long languages still run over slightly (French at 1024 px: 51 px).
- **Phones:** the posts status filter scrolls sideways instead of widening the page (it did in 16 languages).
- 10 new keys `admin.bulk.*`, translated into all 40 locales.
