## Changes
- **Four visibility levels:** public / followers only / friends only / only me. Access is checked on every view against the follows as they are now: unfollowing, or a follow-back ending, takes effect at once. Following needs no approval, so anyone who follows the author sees followers-only posts.
- **Lock page** (403, not indexed, no share card, no content) for people outside the audience. It shows the author's avatar and name, plus:
  - signed out: "Already following? Sign in to see it." and a sign-in button that returns to the post;
  - signed in, not following: a Follow button;
  - friends only, following but not followed back: "You can see this post once they follow you back";
  - mainland China mode: text only.
- **Who sees these posts:**
  - Visible: the author and their followers / friends. They show in the home timeline (the author's own too; only-me posts still don't) and on the profile, where the list and post count follow the viewer's access.
  - Also filtered by access: bookmarks (hidden while access is lost, kept), and reply and quote notifications.
  - Never shown: Discover, search, the post-page aside, share cards / OG images.
  - The profile "Replies" tab still lists comments on public posts only.
- **Interactions:**
  - Allowed for the audience: like, comment, bookmark, share link, report.
  - Repost and quote are refused (404), and the buttons are not shown.
  - Everyone else gets 404, as if the post did not exist.
- **Media:** stays in the private store, served through `/p/{slug}/media/…` after the same access check (`private, max-age=300`, `Vary: Cookie`).
  - Public → followers / friends: media leave the public store and the CDN edge.
  - Between non-public values: nothing moves.
- **Post page:** a note above the post ("Only the author's followers can see this post." / friends), same style as the only-me note.
- **Feed cards:** an icon + label after the time (👥 Followers only / ✓ Friends only), like 🔒 Only me.
- **Compose:** a "Who can see this post" picker next to the short / article toggle (new posts and quotes; edits keep the post's own).
  - Four radios with hints, public checked; works without JS.
  - The button shows the choice (icon + name; icon only on phones), purple when not public.
  - On phones the menu spans the toolbar.
  - A non-public new post never puts its media in the public store.
- **Author's "⋯" menu:** "Make visible only to me / Make public" is replaced by "Who can see: <current>". It opens the four choices in place, with the current one ticked; each choice is a form, so it works without JS.
- **NiceNote / NiceMatrix backend:** no contract change, existing clients keep working.
  - Every `post` object keeps `visibility: public | private` (followers / friends report `private`) and gains `audience` (the exact value). `visibility_changed` carries both.
  - `PATCH visibility: "private"` on a followers / friends post keeps it as it is; `public` makes it public.
  - Documented in `docs/api/nicenote.md`; noted in `docs/plan/cross-agent-requests.md` #6.
- **Terms and privacy policy, all 40 languages:** effective dates bumped to 2026-11-10.
  - Terms: summary, 4.1 and 4.5 now describe choosing who can see a post. 4.5 says that anyone can follow you, so anyone who follows you sees followers-only posts.
  - Privacy: summary, plus the section 4 paragraph on posts that are not public.
- **Code:**
  - One rule: `posts/visibility.ts` (single post, `canSee`) and `db/repos/post-access.ts` (`visibleTo`, the same rule as SQL for lists).
  - `interactions/target.ts` scopes each interaction (public / audience / any).
  - New files: `share/locked-page.ts`, `share/visibility-bits.ts` (icons, labels, notes).
  - Icons added: users, userCheck, check.
- **i18n:** 17 new keys in all 40 locales; `share.action.makePrivate` / `makePublic` removed.
