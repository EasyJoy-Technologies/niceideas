# v1.0.15 — 2026-10-20

## Changes
- Account deletion contract with NiceMatrix (plan §10): `POST /api/internal/v1/account-events`, HMAC-SHA256 signed (`X-NiceMatrix-Timestamp` / `X-NiceMatrix-Signature`, ±300 s), idempotent by `eventId`, out-of-order events ignored.
  - `deletion_requested` → profile and posts offline (410), media leave the public bucket.
  - `deletion_cancelled` → everything back online with the same links.
  - `deletion_completed` → immediate physical deletion of profile, posts, revisions, media, comments, likes, follows.
  - Contract for nicematrix-system: `docs/api/account-events.md`. New env `ACCOUNT_EVENTS_SECRET` (unset = 503).
- Comment times show as relative times ("5 minutes ago") for a week, then the date; full time on hover.
