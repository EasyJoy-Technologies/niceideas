## Added
- External publishing API (plan §9): tokens for the API resource `https://api.niceideas.app` with scopes `posts:read` / `posts:write` / `media:write`, from Logto clients registered in `api_client` (migration 0007: source key, display name, homepage, icon). Same endpoints as first party; `Idempotency-Key` required for creates; an app manages only its own posts (`api:<key>`); `/me/sources` stays first-party only; per-app hourly post ceiling (`RATE_CLIENT_POSTS_PER_HOUR`).
- "From <app>" badge for third-party apps (name + homepage from the registry, default icon).
- `dist/clients.mjs` CLI: list / register / disable / enable third-party clients.
- Contract: docs/api/third-party.md.
