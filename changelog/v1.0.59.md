# v1.0.59 — 2026-10-22

## Added
- Admin console A1 (approved variant A, round 7): own shell with left sidebar (brand, navigation, language + theme tool row above the account row), light and dark.
- Overview: six trend cards (7 days vs the 7 before, sparklines), posts by source (30-day stacked bars, server-drawn SVG), to-do (open reports, hidden comments, bans ending soon), system health, most-liked posts.
- Report queue: reports on the same item merged into one row (open / resolved / dismissed, posts / comments filter); detail panel with every report, author and recent comments of the same visitor; take down or dismiss closes all open reports on the item.
- Posts and comments lists: status filters, search, paging; remove / restore post, hide / restore comment.
- Optional ban when hiding a visitor comment (browser or network address; 1 / 7 / 30 days or permanent); bans list with "Lift ban"; audit log.
- Roles: `admin_member` table (admin / moderator / viewer); `ADMIN_USER_IDS` stay admins. Viewers are read only. Every action needs a reason (suggested reasons offered) and is audited.

## Changed
- `/admin` single page replaced by `/admin`, `/admin/reports`, `/admin/posts`, `/admin/comments`, `/admin/bans`, `/admin/audit`.
- Chart colours as `--ni-chart-1…8` tokens with dark values.
- Admin i18n strings in 40 languages; old `admin.queue|lookup|lookupPlaceholder|notFound` keys removed.

## Database migrations
- `0012_admin_member`: table `admin_member`; indexes on `visitor_ban(expires_at)`, `moderation_action(created_at)`, closed `report(resolved_at)`.
