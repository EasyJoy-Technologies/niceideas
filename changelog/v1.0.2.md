## Changes
- First-party authentication (plan §3): Logto JWT verified via JWKS (ES384), issuer + audience + expiry + 5 s clock tolerance, one JWKS reload on key rotation.
- Audience → source mapping (`https://api.nicematrix.com` → nicenote_intl, `https://apiv3.ej-mobile.cn` → nicenote_cn); ambiguous dual-audience tokens rejected; `client_id` must be in `FIRST_PARTY_CLIENT_IDS` (empty = fail closed).
- Profile auto-creation on first contact with a random, unguessable handle; reserved-handle list; concurrency-safe.
- `apiRoute` wrapper: machine-readable error codes, 500s logged with an errorId and no internals leaked.
- `GET /api/v1/me`.
