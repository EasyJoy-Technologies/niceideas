# v1.0.33 — 2026-10-21

## Added
- Web sign-in with NiceMatrix (Logto "Traditional Web" app): server-side OIDC code flow + PKCE (`client_secret_basic`), ID token verified (signature, issuer, audience, nonce); scope `openid profile` (no email / phone).
  - Routes: `GET /auth/sign-in?next=`, `GET /auth/callback`, `POST /auth/sign-out` (same-origin form; also ends the NiceMatrix session).
  - Session: random 256-bit `ni_sid` cookie (HttpOnly, SameSite=Lax, Secure), only its SHA-256 stored (`web_session`, migration 0004), 30-day sliding expiry; expired sessions purged by the daily maintenance job.
  - First sign-in creates the profile; empty display name / avatar filled from the ID token (never overwrites).
  - Accounts being deleted cannot sign in; `deletion_requested` drops their sessions.
  - Optional silent SSO (`WEB_SILENT_SSO=on`): first site-page visit of a signed-out browser tries `prompt=none` once a day (never on share pages or for bots).
- Wide-screen shell (v3 design): left column bottom = account row (avatar, name, @handle, menu: my profile / sign out) or sign-in card; right column bottom = site links, language, ©; narrow header shows the account avatar or "Join" (→ sign-in).
- Account / language menus close on outside click or Esc.
- 14 i18n keys × 40 locales.
